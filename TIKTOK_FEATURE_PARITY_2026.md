# Blizz — TikTok-style feature parity target (2026)

This package is **Blizz code**, not TikTok's proprietary source code. It implements the current Blizz short-video foundation and documents the feature-parity target for the modern TikTok experience.

## Included in this package
- Full-screen vertical short-video feed
- For You / Following / Friends feed structure
- Double-tap likes and animated heart
- Creator profile navigation
- Follow/unfollow
- Profile video grid
- Camera capture and gallery upload
- Front/rear camera switching
- Microphone/camera permission flow
- Video recording with MediaRecorder
- Full-screen editor workspace
- Timeline / trim / split controls
- Sound browser UI
- Text / stickers / effects / filters / speed / volume
- Voiceover UI
- Server-side FFmpeg processing for trim, speed, volume, filters/effects, text and added audio
- Posting/caption flow
- PostgreSQL-backed accounts, sessions, wallets and social data
- Creator earnings/payout foundation
- Messaging/game/live/profile/settings foundations from the existing Blizz build

## 2026 TikTok feature targets to continue adding
- Voice comments (TikTok announced 60-second voice comments in September 2026)
- Poll comments
- Photo/carousel comments
- Shared Collections
- Shared Feed in direct messages
- Local/Nearby discovery feed
- Stories
- Reposts, playlists and watch history
- Advanced search and discovery
- LIVE co-host/guest tools, moderation and gifts
- Shopping: product showcase, shoppable video/LIVE and shop marketplace where legally/regionally supported
- Creator analytics and monetization tools
- AI-assisted creation/editing, captions, translation and dubbing
- Stronger recommendation controls, keyword/topic controls and safety tooling

## Important
TikTok's production source code, private APIs, licensed music catalogue, recommendation models and proprietary backend are not included and cannot be copied into Blizz. Music must be licensed or supplied through an authorized provider.
